**Mobile Development 2024/25 Portfolio**
# Requirements

Student ID: `c23035992`

**Functional Requirements:**
- Users are able to view a navigation bar to navigate to each page when not in an activity
- Users can exit non-home screen pages via a cancel or back button
- Users can add and delete pets
- Users are able to view information about their pet
- Users can track walks they took with their pet
- Users can select the route they took on the walk using an on-screen map
- Users can filter walks by day using an on-screen calendar
- Users can name their walks
- Users can select what date they took their walk
- Users can select what time they took their walk
- Users can track meals their pet has eaten
- Users can filter pet meals by day using an on-screen calendar
- Users can name their pet meals
- Users can add photos of their pets
- Users can view their photos in the Gallery tab
- Users can name their photos

**Non-Functional Requirements:**
- The app should load each fragment or activity within two seconds
- Users must be prompted to give the app location access when loading the add walk activity
- The app should load walk/meal data within two seconds when selecting a date to view what walks/meals occured on that day
- The app should load photo gallery images within three seconds of opening the fragment
- The app should display a warning message when trying to add a walk if there are no pets in the pets table
