# Retrospective

Student ID: `c23035992`

Reflecting on my app and it's development, I found it hard to get the hang of things at the start simply due to how different Android development is to anything I'd done before, but as I kept persisting, things started to click. The Android official documentation was a huge help, with tutorials that helped me understand numerous features within Android.

My initial plan was to have an app that helped you track all things pet related and I believe the app I've built achieves that. With more time, I would have improved the app further in relation to design, but I also would have liked to implement a community element to the app, such as allowing users to upload and share their favourite walking routes with others on the app.

If I were to do this project all over again, I'd try and experiment more with different UI elements, as I often stuck to the ones I was already comfortable with. While this meant the app functionality was fine, it also led to a lacklustre design. I know Android has endless design possibilities so I'd want to experiment more with layout variety, animations and overall styling to give the app a more professional look.
